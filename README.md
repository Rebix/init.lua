# Neovim config

Personal Neovim configuration for React, TypeScript, Tailwind CSS, Python, and Lua.

## Requirements

- Neovim 0.12+
- Git, Node.js/npm, `make`, a C compiler, and [ripgrep](https://github.com/BurntSushi/ripgrep)

## Install

```sh
git clone git@github.com:Rebix/init.lua.git ~/.config/nvim
nvim
```

Plugins, language servers, and formatters are installed automatically on first launch.

The leader key is `Space`. Use `<leader><leader>` to find files, `<leader>F` to search text, `<leader>h` for
Harpoon, `<leader>u` for the undo tree, and `<leader>lf` to format.
